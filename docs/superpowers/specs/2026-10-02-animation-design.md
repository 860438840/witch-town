## 1. 目标与范围

范围是 **B 档：升级现有动效，再补齐关键时刻**。

**不做**：
- 持续循环的氛围动画，比如夜雾、火星、星星闪烁；
- 规则、服务器、布局的任何改动；
- 美化 B、美化 A 留下的小问题。

**成功标准**：
- 第 2 节列出的时刻在真机上都能看到对应动效。
- 单个动效约 1 秒以内。
- 没有变化时不重画，耗电和发热与现在相同。
- 低端机不卡。

## 2. 每个时刻的动效

| 时刻 | 现在 | 改成 | 时长 |
|---|---|---|---|
| 我抽牌 | 新牌从下面淡入 | 卡背从顶栏的“牌堆”飞到这张牌在手牌里的位置，落下时翻成正面；一次多张时，每张晚 80ms | 约 0.45 秒 |
| 别人抽牌 | 无 | 小卡背从牌堆飞进他的格子 | 约 0.4 秒 |
| 出牌 | 纯色小方块直线飞 | 真卡面沿弧线飞，中途略放大；到达时目标格子闪光，红卡闪红光，其他颜色的牌闪金光 | 约 0.6 秒 |
| 受审 | 无 | 被审的格子红光闪两下，同时左右轻晃 | 约 0.6 秒 |
| 翻身份卡 | 横向翻转 | 保留翻转，用新的身份卡图案；翻出女巫时，翻开后格子冒一下红光 | 约 0.5 秒 |
| 出局 | 格子慢慢变暗 | 变暗的同时，“出局”二字像印章一样从大缩到正常，稍微歪一点盖上去 | 约 0.5 秒 |
| 入夜 / 天亮 | 天色渐变 0.6 秒 | 天色渐变放慢到约 0.9 秒；月亮光晕跟着亮起或退去 | 约 0.9 秒 |
| 轮到谁 | 格子闪三下 | 不变 | — |
| 按钮按下 | 无 | 手指按住时，被按的可点元素下沉 1 像素、变暗一点；松开、拖开或被系统打断时恢复。所有界面所有可点元素都有这个效果 | 跟手 |
| 弹窗出现 | 从底部滑出 | 滑出的同时，背后遮罩从透明渐深 | 约 0.25 秒 |
| 结算页 | 直接出现 | 标题淡入，并从稍大缩到正常；各行从下往上依次滑入；“回到首页”按钮最后出现 | 约 1 秒 |
| 换界面 | 直接切换 | 新界面从夜色里淡出来 | 约 0.25 秒 |

共同规则：
- **动效只补过程**：界面状态永远是最新的。动效播放时按钮照样能点，倒计时照常走。
- **播完即停**：没有循环动画。动效全部结束后停止逐帧重画。
- **变化太多不播**：保留现有规则。两次画面之间版本号跳得太多时（切后台回来、重新进房），不播动效，直接显示结果。

## 3. 实现

### 3.1 发现变化

在现有的画面对比函数里新增三种变化：

- **别人抽牌**：某个座位的手牌数比上一帧多。按增加的张数播放，多张时依次错开。我自己的手牌仍用“新牌出现”这条判断，不重复播放。
- **受审**：事件记录里新出现的受审事件，按被审的人播放。
- **翻出女巫**：现有的翻牌变化，翻开的卡如果是女巫卡，带上“是女巫”的标记。

出牌、翻牌、出局、入夜、轮到谁、弹窗沿用现有判断，只换画法。

### 3.2 画法

- **固定尺寸画、整体缩放**：插画缓存按尺寸存。飞行的卡、出局印章这类会缩放、倾斜的东西，都按固定尺寸画好，再用画布变换整体缩放或旋转。不能每帧按新尺寸画，否则每帧都会新建缓存图。
- **飞行的终点**：我的手牌飞向这张牌排好后的真实位置。别人的牌、出牌飞向格子中心。牌堆位置取顶栏“牌堆”数字所在处。
- **只偏移画的位置**：受审时格子晃动、按下时下沉，都只改画的位置，不改格子的实际位置和点击区域。
- **集中管理**：所有时长集中在现有的时长表里。新增颜色放进调色板，包括按下时的暗色、红光、金光。

### 3.3 界面框架层

- **按下效果**：
  - 手指按下时，记住按到的可点元素。
  - 重画时，这个元素画在下移 1 像素的位置，上面再盖一层按下暗色。
  - 松开、移动超过 8 像素（判定为滚动或拖动）、被系统打断时，清除这个记录并重画。
- **换界面**：切换场景时启动一个 250ms 的动效。重画完所有元素后，盖一层夜色，透明度从 1 降到 0。

### 3.4 弹窗与结算页

- 弹窗：背后遮罩的透明度乘以滑出进度。
- 结算页：从第一次画出时开始计时。标题先出现，接着各行依次出现（每行晚 80ms），按钮最后出现。

## 4. 测试

- **发现变化（单元测试）**：
  - 别人抽牌，包括一次多张；我自己抽牌时不算“别人抽牌”。
  - 受审事件。
  - 翻出女巫和翻出非女巫。
  - 版本跳得太多时，什么都不播。
- **动效画面**：用记录绘制操作的假画布，分别在动效开始、中途、结束时画一次。
  - 出牌和抽牌：中途能画出飞行的卡，结束后不再画。
  - 受审：中途格子有水平偏移，结束后没有。
  - 出局：中途有印章的缩放，结束后印章是正常大小。
  - 结算页：各行按顺序出现。
  - 换界面：遮罩逐渐变淡，最后消失。
  - 按下：按住时有暗色和下沉；松开或拖动后都消失。
- **省电**：
  - 飞行动效连续画 30 帧，插画缓存里的图数量不变。
  - 动效全部结束后，界面框架不再请求重画。
- **画廊**：新增“动效演示”区。每个时刻用真实场景播放，并配一个“重播”按钮，可以在手机浏览器里先看效果。
- **真机（用户做）**：
  - 动效流畅、不卡；
  - 按钮按下的手感正常；
  - 和美化 A 的字体一起检查。

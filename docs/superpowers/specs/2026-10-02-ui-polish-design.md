# 美化 A：界面打磨 — 设计

日期：2026-10-02
上级文档：`2026-09-26-witch-town-design.md`、`2026-09-28-plan-b2-minigame-ui-design.md`（界面）、`2026-10-01-art-design.md`（美化 B 插画）
试验品：分支 `feat/polish` 上的临时风格对照页（三种方向并排），用户选定 **C 酒红金线**
分支：`feat/polish`（从合并了美化 B 的 main 开出）

## 1. 目标与范围

美化分三个子项目：B 插画（已合并）→ **A 界面打磨（本文）** → C 动画特效。

范围选 **B 档：外框 + 字体**。

1. 面板、按钮换成酒红金线风格。
2. 标题类文字换成衬线体。
3. 颜色全部来自调色板。

**不做**：
- 布局、位置、字号的改动；
- 按下效果和一切动画（归子项目 C）；
- 美化 B 留下的小问题：格子里超过 2 张牌不显示“+n”、夜晚光晕每帧新建渐变、重复的椭圆函数、月亮挡住右上角计数。

**成功标准**：
- 所有界面的面板和按钮都是酒红金线风格；
- 第 4 节列出的标题都是衬线体，其余文字不变；
- 小屏 320×568 下没有文字溢出、按钮不出屏；
- 真机上没有方块字。

## 2. 面板

面板分三档，由调用处说明自己是哪一档，不靠“传入颜色等于旧默认色就替换”的判断。

| 档 | 用在哪里 | 外观 |
|---|---|---|
| 大面板 | 底部弹窗、事件记录 | 酒红竖向渐变（上 `#3a0d1c` → 下 `#1e0a14`），1.5px 金线，往里 4px 再一圈淡金线（金色 28% 透明度），宽度 ≥120 时顶边中间一颗金色小菱形 |
| 普通面板 | 牌桌格子、大厅座位、结算行、能力和选择面板里的格子、说书人卡片 | 半透明酒红渐变（上 `rgba(92,14,32,0.6)` → 下 `rgba(34,6,16,0.78)`），1px 暗金线 |
| 信息条 | 牌桌上“我”的状态条、提示条 | 与普通面板相同，只是更窄 |

状态外观（由调用处传入，覆盖档位默认值）：

| 状态 | 外观 |
|---|---|
| 轮到谁、选中 | 2px 金线加金色发光 |
| 可选为目标 | 底色叠一层淡金 |
| 女巫同伴 | 红线 |
| 出局 | 灰线 |

面板圆角保持现状（默认 8，弹窗 16）。

## 3. 按钮

圆角 9。文字一律用衬线体，字号 15 不变。

| 种类 | 外观 |
|---|---|
| 主要 | 酒红竖向渐变（上 `#8a1c34` → 下 `#4a0a18`），1.5px 金线，往里 3px 一圈淡金线（35%），金色文字 |
| 次要 | 深红半透明底 `rgba(60,10,24,0.45)`，1.2px 金线，往里 3px 一圈淡金线（25%），金色文字 |
| 危险 | 底色和线条不变，文字换成更亮的红色 |
| 不可用 / 处理中 | 灰线，不画内线，灰色文字 |

## 4. 字体

原则：**名字和标题用衬线体，要读的内容都用无衬线体。**

衬线体（调色板里现有的标题字体，粗体 + 系统衬线）：
- 首页标题“女巫镇”
- 结算标题
- 牌桌顶栏的阶段标题
- 所有底部弹窗的标题
- 按钮文字
- 大厅房间号
- 规则页小标题

无衬线体（不变）：
- 规则、能力、牌面说明
- 事件记录
- 信息条提示
- 格子里的名字和手牌数
- 倒计时、牌堆数字
- 弹窗副标题

字体来源：手机自带衬线体。iOS 上是宋体粗体；安卓上没有衬线体时会退回无衬线体，不会出现方块字，这一点需要真机确认。字号一律不变。

## 5. 实现

1. **调色板**：第 2、3 节里的颜色值全部进调色板，按用途命名。包括大面板上下两色、普通面板上下两色、主按钮上下两色、次按钮底色、更亮的红字、出局灰线。绘图代码只引用名字，不写颜色值。
2. **收掉实验代码**：
   - 删掉三种风格的切换开关，以及木刻、铁艺两种风格的分支；
   - 删掉风格对照页和它的构建步骤。
3. **保留画廊截图工具**：截图公共部分已经抽成单独文件，留着，画廊页继续用它。
4. **面板**：绘制函数接收“档位”参数（大面板 / 普通 / 信息条），状态外观照第 2 节由调用处传入。现有调用处逐个改成说明档位。
5. **按钮**：四种按钮照第 3 节实现。
6. **文字**：文字绘制增加“衬线”选项。只在第 4 节列出的位置打开。

## 6. 测试

自动测试（客户端测试，用现有的假画布记录绘制调用）：
- 调色板新增的颜色都存在，格式是合法的颜色值。
- 大面板画内金线和顶部菱形，普通面板和信息条都不画。窄于 120 的大面板不画菱形。
- 四种按钮的描边色和文字色符合第 3 节；不可用按钮不画内线。
- 打开衬线选项时用标题字体，不打开时仍是原来的无衬线字体。
- 每个界面都能构建一遍、不报错。三种屏幕尺寸下按钮都在屏幕内。

# 计划 C：15 个角色 — 设计

日期：2026-10-01
上级文档：`2026-09-26-witch-town-design.md`（角色技能表见其 2.9，规则裁定见 2.10）、`2026-09-28-plan-b2-minigame-ui-design.md`（界面）
分支：`feat/characters`（从 `feat/minigame-ui` 开出）

## 1. 目标与范围

给游戏加上 15 个有技能的角色，让它成为完整的女巫镇：

1. 开局发角色：不到 7 人时每人从随机 2 个候选中选 1 个；7 人及以上直接随机发。角色公开。
2. 15 个角色的技能全部由服务器按规则执行（上级文档 2.9 + 2.10 + 本文第 3 节的新裁定）。
3. 需要玩家选择的技能（牧师、说书人、官员、医生）在界面上都能操作；自动技能写进事件记录。
4. 机器人不主动使用技能，自动技能照常生效。

**不做**：美化（下一个子项目）、角色插画、音效。

**成功标准**：4–12 人的带角色对局能在手机上完整玩完；每个角色、每条裁定都有自动测试；牌堆顺序除调整中的说书人外，任何人都拿不到。

## 2. 实现方式：集中查询技能，规则处直接判断

上级文档第 3 节原计划用「钩子插件」实现角色。**改为**：

- 一个函数「某座位此刻生效的技能」：返回该玩家的角色；如果是裁缝，返回右手边（上一个座位方向）第一个活着的玩家的角色，那人死亡则自动顺延。
- 每条规则在需要的位置直接判断这个函数的结果（例如审判线：发起者是法官 → 6；目标是大力士 → 8）。
- 理由：只有 15 个固定角色，大部分是一两行判断；直接写在规则里，读审判、出牌等代码时能一眼看到全部例外，测试也直接。裁缝只在这一个函数里处理。

上级文档第 3 节「钩子」一句随本计划更新为指向本节。

## 3. 规则

### 3.1 数据

- 每个玩家记录：**角色**（原来一直为空）、**技能已用次数**（只有牧师限 2 次、说书人限 1 次、官员限 1 次用到）。裁缝使用限次技能时记在裁缝自己身上，因此与原角色分开计算（上级裁定 5）。
- 选角色阶段记录每人的 2 个候选。
- 红卡记录额外保存「原来是哪张卡」：医生当作目击打出的辩护，在目标面前按目击 7 点计算，进入弃牌堆时还原成辩护。

### 3.2 开局

- 不到 7 人：新阶段「选角色」。每人同时从 2 个互不重复的随机候选中选 1 个（所有人的候选合起来也不重复），限时 30 秒，超时随机。全部选定后进入第一夜放黑猫。
- 7 人及以上：创建局面时随机发角色（互不重复），直接进入第一夜。
- 第一夜女巫不能选女仆放黑猫（上级裁定 4）。

### 3.3 角色行为

| 角色 | 行为 |
|---|---|
| 医生 | 出「辩护」时可选「当作目击」：给目标加 7 点红卡，可以触发审判；不受部长削弱（上级裁定 2）；受信徒限制，不能打给自己 |
| 乞丐 | 抢劫、纵火以乞丐为**第一个目标**（被抢、被烧的一方）时无效，这张牌直接进弃牌堆。**新裁定 C1**：抢劫中乞丐是接收手牌的一方时照常生效 |
| 地主 | 正常抽牌抽到的 2 张**都是指控**时，公开展示并再抽 1 张；再抽的那张不再触发。**新裁定 C2**：牧师从弃牌堆拿牌不算抽牌，不触发 |
| 法官 | 他打出的红卡、以及他打出的嫁祸转移的红卡，使目标达到 6 点即审判；对大力士也按 6（上级裁定 1） |
| 牧师 | 整局 2 次：回合开始、还没抽牌也没出牌时，改为从弃牌堆选 1–2 张非黑卡加入手牌，然后回合结束。弃牌堆没有非黑卡时不能使用 |
| 说书人 | 整局 1 次：回合开始、还没抽牌也没出牌时，进入「调整牌堆」阶段（3.4），结束后回到他的回合，仍可选抽牌或出牌 |
| 裁缝 | 技能实时等于右手边第一个活着的玩家（第 2 节）；限次技能单独计次 |
| 家庭主妇 | 其他玩家的身份卡因**审判或黑猫**被翻开时，从牌堆顶抽 1 张（上级裁定 6）；因死亡或自首翻开不算；自己的身份卡被翻开不算 |
| 农民 | 其他玩家死亡时，获得其手牌和面前的蓝卡（含黑猫），全部放入手牌；死者的红卡、绿卡照常进弃牌堆。农民自己在同一事件中死亡则不获得；多人同时死亡按座位顺序结算（上级裁定 10） |
| 小孩 | 他发起的审判结束后，丢弃他自己面前所有「指控」和「证据」（目击保留） |
| 部长 | 别人对他打出的「证据」只算 1 点。**新裁定 C3**：别处的证据被嫁祸转到他面前仍按原点数（点数在打出时确定） |
| 官员 | 整局 1 次：夜晚自首时可以不翻身份卡，照样当晚免疫击杀 |
| 大力士 | 对他的审判线为 8 点（法官出牌时为 6） |
| 女仆 | 黑猫、情侣打给她时无效，直接进弃牌堆；嫁祸转给她的黑猫、情侣也直接进弃牌堆 |
| 少女 | 她打出的牌引发审判时，审判开始前她先抽 2 张牌，本回合可以继续使用 |

### 3.4 说书人调整牌堆

- 阶段限时 2 分钟，其他人等待。
- 说书人看到完整牌堆（顶到底），提交一个新顺序；新顺序必须是当前牌堆的重新排列，否则报错。
- 超时按原顺序不变。
- 回到他的回合时，回合计时重新开始（90 秒）。

### 3.5 摸到黑卡：立即结算（新裁定 C4）

家庭主妇、少女、地主等在非正常抽牌时也可能摸到「夜晚」或「传染」。规则：

> 黑卡立即结算，结算完回到被打断的流程继续；如果摸到的是「夜晚」，被打断的流程走完后，当前玩家的回合结束，由下一位开始。

- 例 1：家庭主妇在审判翻牌后摸到夜晚 → 立即夜晚 → 回来完成审判收尾（丢弃被审判者红卡）→ 当前回合结束。
- 例 2：家庭主妇在黑猫翻牌后摸到夜晚 → 立即夜晚 → 回来继续传染的盲抽 → 当前回合结束。
- 例 3：少女审判前摸到夜晚 → 立即夜晚 → 回来继续审判（被审判者若已在夜里死亡则取消审判）→ 少女回合结束。
- 摸到传染：立即结算传染，结算完回到原流程，回合不结束。
- 被打断的流程在恢复时要重新检查条件（相关玩家是否还活着、游戏是否已结束）。

### 3.6 公开与保密

- 公开：每人的角色；裁缝当前复制的角色；限次技能剩余次数；**弃牌堆内容**（实体游戏中可查看，改为公开）；「牌堆被调整过」这一事实。
- 仅本人：选角色阶段的 2 个候选。
- 仅调整中的说书人：牌堆顺序（只在「调整牌堆」阶段的私密视图里）。其他任何时候任何人都拿不到。

### 3.7 事件记录

新增：角色发放 / 选定；技能生效（例如「女仆 P2：情侣无效」「地主 P4 展示 2 张指控，再抽一张」「家庭主妇 P5 抽了一张牌」「官员 P1 自首（未翻牌）」「牧师 P3 从弃牌堆拿了 2 张」「说书人 P6 调整了牌堆」）。

## 4. 服务器（云函数）

- 时限：选角色 30 秒；说书人调整牌堆 2 分钟；调整结束回到回合时重新计 90 秒。
- 超时：选角色 → 未选的人随机；调整牌堆 → 按原顺序提交。
- 机器人：选角色随机；从不主动使用技能。
- 新操作的参数按白名单校验，不合法统一报「操作参数无效」：选角色（第几个候选）、牧师拿牌（1–2 张卡的编号）、开始调整牌堆、提交新顺序（卡编号列表，长度有上限）、自首的「不翻牌」标记、辩护的「当作目击」选项。
- 部署：局面数据结构有变化，部署新云函数时不能有正在进行的对局。

## 5. 界面

- **选角色面板**：两张角色卡并排（角色名 + 技能说明），点选后确认；倒计时；选完显示「等待其他人选择（x/n）」。
- **桌面格子**：名字后加角色，如「P2·法官」；裁缝显示「P3·裁缝→法官」。点格子的详情显示技能说明。
- **我的信息栏**：「你（P1·牧师）」。
- **顶栏**：点弃牌数打开弃牌堆列表。
- **回合按钮**：牧师多「从弃牌堆拿（剩 n 次）」→ 弃牌堆非黑卡网格，选 1–2 张确认；说书人多「调整牌堆（剩 1 次）」→ 全屏拖拽列表（按住右侧 ≡ 拖动，靠近边缘自动滚动，2 分钟倒计时，确认 / 还原）。其他人看到「说书人正在调整牌堆 m:ss」。
- **夜晚**：官员的自首区多「不翻牌自首（剩 1 次）」。
- **出牌**：医生选中辩护时先选「当作辩护 / 当作目击（7 点）」。
- **事件记录**、**规则页**（新增「角色」一节）。
- **界面框架**：新增按住拖动（按下 → 移动 → 松开，拖动时屏蔽滚动，靠近边缘自动滚动）。
- 小屏 320×568 下所有新面板不重叠、按钮在屏幕内。

说书人拖拽的手感已用网页原型在手机上试过（2026-10-01）：两分钟内把第 34 张拖到第 1 张很轻松。

## 6. 测试

- **引擎**：每个角色至少一条；上级 13 条裁定与本文新裁定 C1–C4 各有测试；裁缝随右边玩家变化与死亡顺延；限次技能用尽后拒绝；黑卡插入流程的三个例子；医生辩护进弃牌堆后还原；总卡数守恒。
- **服务器**：新操作参数校验；新阶段超时处理；牌堆顺序只出现在调整中说书人的私密视图；候选只出现在本人私密视图。
- **客户端**：每个新面板能完成操作；320×568 下不重叠；拖拽排序结果正确（按下、移动、边缘滚动、松开）。
- **真机**：多人实测一局带角色的对局。
